# État de la traduction française

Version de travail du 14 novembre 2026, basée sur le commit anglais `9721dac0d22538423eb2db63a212a7d3f3ec2017`.

105 pages traduites avec assistance IA ; relecture linguistique et technique partielle. Les 303 blocs de code et les destinations des liens Markdown sont conservés. Des ancres explicites conservent les références aux titres anglais. Les procédures historiques ne sont pas toutes validées avec Joomla 6/JCB 6.2.0.

Les 11 fiches HTML de `help-documents/` sont une adaptation française relue des aides contextuelles standard de JCB 6.2.0. Elles couvrent les mêmes opérations, avec une terminologie corrigée pour le déverrouillage. Ces fichiers ne sont pas importés automatiquement par JCB.

Le chargement multilingue du tableau de bord nécessite une modification distincte de JCB. L’ajout de ce dossier ne suffit pas à modifier le comportement de l’extension.

Contribution préparée par Yann Gomiero. Merci de signaler les formulations à améliorer et les différences de version avant toute annonce d’une traduction validée pour la production.
