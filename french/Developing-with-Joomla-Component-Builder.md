<a id="developing-with-joomla-component-builder"></a>
# Développer avec Joomla Component Builder

Cette page explique comment les ressources écrites et vidéo de Joomla Component Builder (JCB) fonctionnent ensemble. Le texte original était une transcription libre sur la documentation de la série de didacticiels ; la version réécrite vous donne un guide concis que vous pouvez suivre lors de la planification de votre propre routine d'étude.

<a id="why-these-transcripts-exist"></a>
## Pourquoi ces transcriptions existent

Les leçons vidéo répertoriées sur la page [Accueil](./index.md) sont transcrites afin que chaque instruction orale soit disponible sous forme de texte consultable. Chaque chapitre comprendra à terme :

- Dialogue verbatim qui clarifie la terminologie utilisée dans les vidéos.
- Captures d'écran tirées de la leçon avec des liens directs vers le moment où elles apparaissent sur YouTube.
- Liens contextuels vers la documentation ou les outils complémentaires mentionnés dans l'enregistrement.

En conséquence, vous pouvez apprendre visuellement, lire ou vérifier rapidement un sujet sans relire une vidéo entière.

<a id="tips-for-studying-effectively"></a>
## Conseils pour étudier efficacement

- **Suivez vos progrès :** copiez les marqueurs de la chronologie de la documentation dans vos propres notes. Lorsque vous revenez à un chapitre, vous pouvez revenir directement à la minute où vous vous êtes arrêté.
- **Annotez pendant que vous apprenez :** ajoutez des rappels ou des TODO à côté des concepts que vous devez revisiter. Le Markdown structuré facilite le collage de sections dans votre éditeur préféré.
- **Changer de modalités :** mettez la vidéo en pause, examinez les étapes écrites, puis reprenez la lecture. L’alternance entre les formats renforce la compréhension.
