Gérer les champs

Cette liste permet de gérer les champs. Les actions disponibles dépendent de vos autorisations et de la sélection en cours.

Créer

Cliquez sur Nouveau dans la barre d’outils. Renseignez les valeurs nécessaires dans le formulaire, puis enregistrez la fiche.

Modifier

Cliquez sur le nom d’une fiche, ou cochez sa case puis cliquez sur Modifier. Vous pourrez modifier ses valeurs si votre compte dispose des autorisations nécessaires.

Modifier l’état

Cochez les fiches concernées, puis choisissez l’action souhaitée : publier, dépublier, archiver ou mettre à la corbeille. L’action s’applique à toutes les fiches sélectionnées.

La mise à la corbeille ne supprime pas immédiatement les données. Utilisez le filtre d’état pour afficher les éléments dans la corbeille. Vous pouvez ensuite les sélectionner et modifier leur état pour les récupérer, ou cliquer sur Vider la corbeille pour les supprimer définitivement. Cette dernière opération est irréversible : sauvegardez vos données avant de l’utiliser.

Déverrouiller une fiche

Lorsqu’une personne ouvre une fiche, Joomla la verrouille pour éviter les modifications simultanées. Un cadenas indique ce verrouillage ; survolez-le pour identifier la personne concernée et la date.

JCB propose un déverrouillage automatique dont le délai se règle dans les paramètres du composant. Si une fiche reste verrouillée après la fermeture de son formulaire, un compte autorisé peut la sélectionner et utiliser Déverrouiller. Vérifiez auparavant que personne ne travaille encore dessus.

Traitement par lots

Lorsque cette action est disponible, sélectionnez plusieurs fiches puis cliquez sur Traitement par lots. Choisissez les valeurs à appliquer et l’opération proposée, mise à jour ou copie, puis lancez le traitement. Contrôlez ensuite le résultat sur les fiches concernées.

Exporter et importer

L’exportation et l’importation permettent de traiter plusieurs fiches dans un tableur. Elles ne remplacent pas une sauvegarde complète du site ni l’exportation d’un modèle JCB avec ses dépendances.

Exporter

Sélectionnez les fiches puis cliquez sur Exporter les données. Pour sélectionner toute la liste, réglez d’abord sa pagination sur Tous, vérifiez les filtres actifs et cochez la case en tête du tableau. Les fiches placées dans la corbeille ne sont pas incluses si le filtre les exclut. Enregistrez le fichier proposé sur votre ordinateur.

Importer

Pour mettre à jour une fiche existante, conservez son identifiant. Pour créer une nouvelle fiche, laissez la colonne d’identifiant vide. Le plus simple est de partir d’un export récent, puis de modifier les valeurs dans ce fichier sans altérer les identifiants des fiches à mettre à jour.

Cliquez sur Importer les données, puis choisissez le fichier sur votre ordinateur, son chemin sur le serveur ou son adresse directe, selon les options proposées. Lancez l’envoi ou la récupération du fichier.

Associez ensuite chaque colonne du tableur au champ correspondant. Les en-têtes d’un export non modifié peuvent permettre une association automatique ; vérifiez néanmoins chaque correspondance. Ignorez les colonnes qui ne doivent pas être traitées. Cliquez sur Continuer, puis contrôlez le message de résultat et les données importées.

Résoudre un problème

Si une action échoue, lisez le message d’erreur et corrigez les valeurs ou les conditions indiquées avant de recommencer. Si le problème persiste, contactez l’administration du site en précisant l’action effectuée et le message reçu, sans communiquer de mot de passe.
