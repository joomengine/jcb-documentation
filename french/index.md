# Bienvenue dans le centre d'apprentissage Joomla Component Builder

## Commencez ici

Ces didacticiels vous donneront une compréhension pratique du fonctionnement de Joomla Component Builder (JCB). La documentation ci-dessous associe chaque procédure pas à pas aux références chronologiques de la vidéo qui l'accompagne afin que vous puissiez passer directement au moment dont vous avez besoin. Pendant que vous lisez, portez une attention particulière à la façon dont les **Vues d'administration personnalisées** étendent le backend de Joomla et à la façon dont le guide actualisé des **Plugins Joomla** documente l'automatisation en arrière-plan. JCB capture désormais la manière dont les requêtes dynamiques, les modèles, les mises en page, les blocs de code réutilisables et les services pilotés par des plugins s'assemblent afin que l'interface utilisateur et la logique des événements de votre composant restent alignées.

Une révision de cette base de connaissances est en cours pour ajouter des délais et peaufiner chaque transcription. Les chapitres un à soixante et onze incluent déjà des transcriptions brutes et sont activement en cours d'édition. Les mises à jour des progrès continueront d'apparaître dans le titre du chapitre en cours de peaufinage, et de nouvelles annonces seront publiées sur le forum communautaire une fois le chapitre terminé.

Pour un aperçu de la qualité cible, consultez le chapitre entièrement édité [Types de champs](./Field-Types.md). Le travail progresse à travers les leçons précédentes avant de continuer avec les chapitres six à soixante et onze. Associez-le au nouveau [Présentation des champs JCB](./JCB-Fields.md) chaque fois que vous avez besoin d'un rappel sur la façon dont les définitions de champs régissent le schéma, le rendu, la validation et le partage de la base de données.

Si vous avez des questions ou souhaitez vous impliquer, rejoignez le projet [discussions](https://github.com/orgs/joomengine/discussions). Vous pouvez également explorer la [playlist YouTube](https://www.youtube.com/playlist?list=PLQRGFI8XZ_wtGvPQZWBfDzzlERLQgpMRE) complète des didacticiels JCB.

> 🧱 **Mise à jour : fondation JCB Fields** – Le [chapitre JCB Fields](./JCB-Fields.md) consolide désormais la façon dont les définitions de champs contrôlent le schéma de la base de données, le rendu, la validation, le partage et la gestion des versions basée sur le référentiel afin que vous puissiez expliquer rapidement le flux de travail aux nouveaux coéquipiers.
> 🆕 **Dynamic Gets approfondissement** – Le [guide Dynamic Gets](./dynamicGet.md#overview) actualisé  explique désormais comment le générateur de requêtes visuel sélectionne les tables, les jointures, les filtres, l'ordre et le regroupement, comment plusieurs get se combinent dans une seule vue et comment les workflows Init/Reset/Fork maintiennent le contrôle de version des requêtes complexes.

> 📌 **Nouveau : Explication de l'architecture de vue de site** – Commencez par le guide révisé [Ajout de vues de site](./Adding-Site-Views-to-a-Component.md) pour voir comment les acquisitions dynamiques, les modèles, les mises en page, les espaces réservés de code personnalisés et les bibliothèques JS/CSS facultatives assemblent votre interface. Associez-le au chapitre mis à jour [Configuration du modèle](./Template-Setup.md) pour comprendre comment ces wrappers modulaires façonnent les expériences du site et de l'administrateur et comment les maintenir à jour dans les projets.

> 🧱 **Nouveau : aperçu des mises en page JCB** – Le [guide JCB Layouts](./JCB-Layouts.md) dédié  explique désormais comment initialiser, réinitialiser, pousser et forker les référentiels de mise en page dans l'onglet Layouts afin que votre balisage réutilisable reste contrôlé en version aux côtés de vos composants.

> 🔌 **Nouveau : Plugins Joomla JCB** – Lisez la [Présentation des plugins Joomla](./Joomla-Plugins.md) pour découvrir comment la logique événementielle se déplace avec votre composant. L'article explique maintenant comment les plugins sont regroupés, configurés et livrés avec chaque build afin que vous puissiez documenter l'automatisation à côté des fonctionnalités des composants qui en dépendent.

> 🧩 **Mise à jour : flux de travail de code personnalisé** – Le nouveau [Présentation des codes personnalisés JCB](./JCB-Custom-Codes.md) explique comment les extraits manuels basés sur des arguments et l'automatisation basée sur le hachage se complètent, y compris les règles d'encodage, les allers-retours de chaînes de langue et les conseils de collaboration.

> 📦 **Nouveau : Modules JCB Joomla** – Explorez la présentation des [Modules JCB Joomla](./Joomla-Modules.md) pour comprendre comment les modules se compilent avec vos composants, héritent du versioning Reset/Fork et fournissent des widgets réutilisables aux positions des modules Joomla.
